# Freelanceprosjekter

Jobber som freelancer for å bygge erfaring. Sammarbeider med klubber, butikker og mer. Utvikler webapplikasjoner og programvare som kan brukes internt.

## Merkatå bruktbutikk
Dette prosjektet er nettside utviklet for bruktbutikken på Merkatå. Den går ut på å vise frem produkter og informasjon om butikken på en
oversiktlig og behagelig måte for kunder. I tillegg inkluderer den administratorrettigheter som tillater tillegg, sletting og redigering av produkter.
Utviklet i Next.JS og Supabase.

https://github.com/JosefBurkan/Merkata_Brukt_Butikk

Lenke til nettsiden: https://merkata-bruktbutikk.vercel.app

## LeseLy boklubb
Dette prosjektet er en nettside utviklet med samme teknologi som Merkatå sin nettside. Den skiller seg litt ut ved at den fokuserer mer på å
inkludere brukerne ovenfor å vise dem produkter. Her kan brukere lese om klubben, melde seg på newsletter og eventer, og lese om månedens bok. I tillegg
så vil de motta eposter etter å ha meldt seg på eventer/newsletter.

Administrator kan slette/redigere og legge til eventer, og lage/redigere og slette innlegg.
